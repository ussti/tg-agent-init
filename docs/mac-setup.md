# Подготовка Mac к установке агента

Агент живёт на сервере, а не на вашем компьютере. Mac нужен только как окно на сервер,
поэтому ставить на него ничего не надо: ни git, ни GitHub, ни Homebrew, ни Xcode, ни Claude
Code. Всё это установщик поставит сам, уже на сервере.

## Что нужно заранее

1. **Сервер.** Ubuntu 24.04 (или 22.04), от 4 ГБ памяти: меньше Claude Code не рекомендует. После покупки провайдер присылает
   адрес сервера и пароль от пользователя root. Сохраните их.
2. **Подписка Claude** Pro или Max на claude.ai. Войти в неё придётся один раз во время
   установки: терминал покажет ссылку, вы откроете её в браузере на Mac.
3. **Бот в Telegram.** Напишите @BotFather, команда `/newbot`, придумайте имя и адрес бота.
   BotFather пришлёт токен. Его никуда не пересылайте, он понадобится в терминале.
4. **Свой Telegram ID.** Напишите @userinfobot, он ответит числом. Это и есть ID.
5. **По желанию** бесплатный ключ Groq (console.groq.com), чтобы агент понимал голосовые
   сообщения. Можно добавить и позже.

## Терминал

Терминал уже есть в macOS: Cmd+Пробел, наберите «Терминал», Enter. Или Finder → Программы →
Утилиты → Терминал.

Вставка в терминал работает как обычно, через Cmd+V. Команду запускает Enter.

## Проверка входа на сервер

Сделайте это до занятия, чтобы на нём не тратить время на доступ.

```bash
ssh root@АДРЕС_СЕРВЕРА
```

Вместо `АДРЕС_СЕРВЕРА` подставьте адрес из письма провайдера.

- При первом входе терминал спросит `Are you sure you want to continue connecting`.
  Напечатайте `yes` и нажмите Enter.
- Потом он попросит пароль. Символы при вводе не видны, даже звёздочек нет, так и должно
  быть. Вставьте пароль через Cmd+V и нажмите Enter.
- Если вход удался, строка в конце сменится на что-то вроде `root@имя-сервера:~#`.
  Выйти обратно на Mac можно командой `exit`.

Если пишет `Permission denied`, пароль не тот: скопируйте его заново из письма или сбросьте
в панели провайдера. Если долго висит и пишет `timed out`, проверьте адрес.

## Ключи только в терминале

Токен бота, пароль сервера и ключи вводятся только в терминале. В Telegram, в том числе
своему же агенту, их не отправляйте.
